## Editing

Edit `operations/timetable.json`, then run `python3 operations/generate_timetable.py` from the project root. This regenerates `TIMETABLE.md` and `timetable.html`. The website imports the same JSON. Direct edits to this Markdown file are possible but will be overwritten on regeneration.
